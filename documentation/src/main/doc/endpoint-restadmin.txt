[[endp-rest-admin]]
=== RESTful Administration API endpoint

Endpoint type:: +RESTAdmin+
Binding:: RESTful
Exposed paths:: +/v1/*+

This endpoint exposes a RESTful API to Unity features. 
The endpoint does not require any specialized configuration.

The documentation of the REST API is available on a separate page
link:rest-api-v1.html[REST API] 

Runtime OpenAPI documentation is enabled by default. Set +unity.endpoint.rest.enableOpenApi=false+ in this
endpoint's configuration to disable its live +openapi.json+, +openapi.yaml+ and API reference UI resources.
This shared property uses the same name for Admin and UpMan and applies independently to each endpoint
instance. API operations remain available, and build-time YAML and HTML documentation generation is unaffected.
