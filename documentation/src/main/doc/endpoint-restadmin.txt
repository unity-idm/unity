[[endp-rest-admin]]
=== RESTful Administration API endpoint

Endpoint type:: +RESTAdmin+
Binding:: RESTful
Exposed paths:: +/v1/*+

This endpoint exposes a RESTful API to Unity features. 
The endpoint does not require any specialized configuration.

The documentation of the REST API is available on a separate page
link:rest-api-v1.html[REST API guide] and the generated
link:admin-openapi-v1.html[Administration API reference].

The +unity.endpoint.rest.openApiPublication+ setting controls which runtime docs this endpoint publishes.

* +disabled+ (default) serves no runtime API docs.
* +specification+ publishes +openapi.json+ and +openapi.yaml+.
* +specificationAndUI+ also publishes the Scalar interface at +api-docs+ below the endpoint path.

Published documentation is accessible without authentication. Requests submitted from Scalar use the REST
endpoint's configured authentication and authorization. Each endpoint instance has its own publication setting.
The build-time YAML and HTML references are generated in every mode.
